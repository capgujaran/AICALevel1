AI drafting gateway

Core checks work locally. To use a language model, connect a separately hosted, approved gateway. Provider credentials are read on the server from .env. Leave the token blank for the default local demo; hosted gateways require an access token.

Access tokens stay in memory and clear on reload. The local gateway URL is filled automatically. Each draft request asks for permission before sending a minimal, aliased finding summary.

Send this finding for AI drafting?

The gateway will receive the control name, current narrative and anonymous evidence aliases. It will forward that summary to its configured model provider. Raw extracts, supplier identifiers, invoice identifiers and amounts are excluded. Review your edited narrative for any details you have added.

Inspect the exact payload
AI can draft impact, recommendations and questions. It cannot change the control result, amount, evidence, or review decision.

  
Clear the current workspace?
Clearing the workspace removes the current extracts, findings and review decisions from memory. Download your workpaper first if you need to keep them.
